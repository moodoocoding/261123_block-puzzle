# 블록 퍼즐 챔피언

2026 충북 AI 페스티벌 체험 부스용 웹앱입니다. 초등학생이 만든 8×8 블록 퍼즐 게임에 이름 입력과 오늘의 랭킹을 더했습니다.

- `index.html`: 랭킹을 더한 앱 (시작할 때 이름 입력, 게임이 끝나면 내 등수와 TOP 5, 🏆 랭킹 버튼, 🏁 끝내고 기록하기)
- `board.js`: 부스 공용 랭킹 (다른 부스 앱과 같은 파일, Firebase `block` 컬렉션 사용)
- `원본_학생작품.html`: 학생이 만든 원본

체험하기: https://moodoocoding.github.io/261123_block-puzzle/
